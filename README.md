# Tap Counter

A simple desktop counter: two big panels, one count each, saved in the browser.

**Live:** https://dclnc.github.io/tap-counter/

- **Click** online or **E&R** to add one.
- **Right-click** a panel to undo (take one off). Counts never go below zero.
- Keyboard: Tab to a panel, Enter/Space adds, Backspace/Delete undoes.
- **Reset** (with a confirm) sets both back to zero.
- Counts persist in `localStorage`.
- Each click plays a synthesised mechanical key-switch sound (press + release); undo plays a softer double click.

On narrow screens the panels stack vertically.

Hosted on GitHub Pages from this repo’s `main` branch.
