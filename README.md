# Tap Counter

A simple mobile counter: two big panels, one count each, saved in the browser.

**Live:** https://dclnc.github.io/tap-counter/

- Tap **online** or **E plus R** to add one.
- **Reset** (with a confirm) sets both back to zero.
- Counts persist in `localStorage`.
- Add it to an iPhone home screen via Share → Add to Home Screen.

Hosted on GitHub Pages from this repo’s `main` branch.
